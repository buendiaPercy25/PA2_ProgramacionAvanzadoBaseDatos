<h2 data-importer="text" align="left">DESCRIPCIÓN:</h2>

### 

<p data-importer="text" align="left">
En este proceso de aprendizaje 1, el trabajo consiste en implementar y consultar una base de datos para una tienda de productos tecnológicos usando Microsoft SQL Server.<br><br>
La base de datos nos permite gestionar información con relación a clientes, productos y ventas, aplicando los conceptos de SQL desarrollados durante el curso.
</p>

### 

<h2 data-importer="text" align="left">OBJETIVO:</h2>

### 

<p data-importer="text" align="left">
El objetivo del proyecto es diseñar e implementar una base de datos funcional para una tienda tecnológica y realizar consultas que permitan obtener información útil sobre los clientes, productos y operaciones de venta.
</p>

### 

<p data-importer="text" align="left">
Para ello se aplican conceptos de:<br><br>
- Creación de bases de datos y tablas.<br>
- Tipos de datos.<br>
- Restricciones de integridad.<br>
- Inserción de registros.<br>
- Consultas SELECT.<br>
- Filtros mediante WHERE.<br>
- LIKE, BETWEEN, IN y EXISTS.<br>
- Funciones de cadena, numéricas y de fecha.<br>
- Funciones de agregación.<br>
- GROUP BY y HAVING.<br>
- INNER JOIN.<br>
- LEFT OUTER JOIN.<br>
- CASE.<br>
- UNION.<br>
- Subconsultas.
</p>

### 

<h2 data-importer="text" align="left">DESARROLLO:</h2>

### 

<p data-importer="text" align="left">
El equipo desarrolló el proyecto paso a paso. Primero se creó la base de datos con sus tablas, relaciones y restricciones. Después se insertaron los datos y se realizaron las consultas solicitadas en cada actividad. Finalmente, se organizaron los scripts en GitHub y se verificaron los resultados obtenidos.
</p>

### 

<h2 data-importer="text" align="left">SOLUCIÓN PROPUESTA:</h2>

### 

<p data-importer="text" align="left">
Se propuso un modelo físico de base de datos en Microsoft SQL Server para gestionar los clientes, productos y operaciones de la organización. Para esto, se crearon scripts SQL que permitieron definir las tablas, establecer las relaciones entre ellas, aplicar restricciones y cargar datos válidos.<br><br>

A continuación, se diseñaron consultas utilizando SELECT y WHERE, con filtros, funciones y agrupaciones, con el objetivo de extraer información relevante y verificar que los resultados coincidan con los datos almacenados. También se desarrollaron consultas que combinan varias tablas mediante INNER JOIN y OUTER JOIN, incluyendo CASE y UNION según sea necesario para organizar y clasificar la información.<br><br>

Además, se implementaron subconsultas y consultas con EXISTS para resolver requerimientos que dependen de resultados obtenidos de otras consultas. Los resultados finales permiten comprobar el correcto funcionamiento del modelo y demostrar el uso de los contenidos trabajados en las sesiones 1 a 4 de la evaluación.
</p>

### 

<h2 data-importer="text" align="left">CÓMO EJECUTAR O REVISAR EL PROYECTO:</h2>

### 

<p data-importer="text" align="left">
Para ejecutar y revisar el proyecto, se usa Microsoft SQL Server. Primero se debe ejecutar el script TechBD.sql, que contiene la creación de la base de datos, tablas, relaciones, restricciones e inserción de datos.<br><br>

Una vez creada la base de datos, se pueden ejecutar los scripts de las actividades en el siguiente orden:<br><br>

Actividad2.sql — consultas de selección, filtros, funciones y agrupaciones.<br>
Actividad 3.sql — consultas multitabla, JOIN, CASE y UNION.<br>
Actividad 4.sql — subconsultas y consultas con EXISTS.<br><br>

Para revisar el proyecto, se deben verificar los resultados obtenidos por cada consulta y comprobar que sean coherentes con los datos registrados en la base de datos. También se pueden revisar los scripts y las evidencias incluidas en el repositorio para comprobar el desarrollo de cada actividad.
</p>
